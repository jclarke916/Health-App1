Centurion — Privacy Policy

Last updated: 20 September 2026
Centurion is a private health dashboard used by two people in one household. It is not offered to the public, has no sign-ups, and sells nothing. This page sets out exactly what it does with data, because it connects to the Oura API.

Who runs it

Centurion is built and operated by its two users for their own use. There is no company behind it, no staff with access, and no third party involved in running it.

What data it handles

  • Oura Ring data — sleep, readiness, activity, workouts, heart-rate variability and resting heart rate, retrieved from the Oura API with the explicit authorisation of the account holder.
  • Apple Health data — optional. Activity rings, steps, sleep and workouts, sent by the user's own iPhone if they choose to set that up.
  • Information entered by hand — meals and water, body-composition scans, laboratory results, and date of birth.

Where it is stored

  • On the users' own devices, in the browser's local storage.
  • On a private server on the owner's home network, reachable only over a private VPN (Tailscale). It has no public address and is not exposed to the internet.

Nothing is stored on any hosting provider, analytics platform or cloud database. The app's code is served as a static page by GitHub Pages, which receives no health data of any kind.

Who it is shared with

Nobody. Health data is never sold, rented, published or shared with any third party. There is no advertising, no analytics, no tracking pixels and no crash reporting.

Artificial intelligence features

The coaching, meal-estimating and document-reading features run on a self-hosted language model on the same private home network. Health data is not sent to OpenAI, Anthropic, Google or any other external AI provider.

How Oura data is used

Oura data is requested read-only and used solely to show the user their own metrics inside the app and to calculate their daily readiness, nutrition and activity summaries. It is never sent anywhere else. Access is granted through the Oura OAuth2 flow and can be withdrawn at any time at cloud.ouraring.com, which immediately stops all further access.

How long it is kept

Data is kept until the user deletes it. It can be removed at any time by clearing the app data on a device and deleting the files on the home server. No one else holds a copy.

Children

Centurion is used by two adults. It is not intended for, or made available to, anyone under 18.

Changes

If this policy changes, the date at the top of this page changes with it.

Contact

Questions about this policy can be raised at github.com/jclarke916/Health-App1/issues.
